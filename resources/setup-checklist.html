Session 02 — Setup evidence

Required submission · five genuine screenshots from your own computer. Main editor: VS Code. First app: run in Chrome or Edge.

Required evidence

  1. 01-vscode-extensions.png
    Flutter and Dart VS Code extensions visible as installed and enabled.
  2. 02-dart-version.png
    Actual terminal command dart --version and its result. Use two dashes.
  3. 03-flutter-doctor.png
    Actual flutter doctor command and complete diagnostic output; include extra screenshots if longer than one screen.
  4. 04-flutter-devices.png
    flutter devices showing Chrome or Edge as a web target.
  5. 05-flutter-web-app.png
    Default generated Flutter app running in Chrome or Edge. The app should actually launch, not just a copied book illustration.

What to do

  1. Install Git, VS Code, Flutter extension (installs Dart extension), and Flutter SDK.
  2. Verify tools in VS Code's terminal.
  3. Flutter: New Project → Application, name setup_check_app.
  4. Select Chrome/Edge in VS Code, press F5 to launch.
  5. Capture the five screenshots above. Submit through the location specified by your instructor.

Blocked by weak internet or an install error? Submit the screenshots available, a screenshot of the error, and a brief note describing what worked, what failed, and what you will do next. Do not fabricate success or use sample screenshots.

Optional: real Android phone

After completing the web pathway, the course site provides Android Studio + Android SDK + physical device instructions for Xiaomi/Redmi/POCO/Samsung. Optional evidence: phone listed in flutter devices and the same app running on the phone. This does not replace required web screenshots.
